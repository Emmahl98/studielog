Google Sheets verbinden

Voor de eerste verbinding is een Google OAuth-client-ID nodig. Daarna kun je met je eigen Google-account inloggen.

Dit is een openbare app-ID, geen wachtwoord of clientsleutel.

Eenmalig instellen
  1. Maak een project in de Google Cloud Console en schakel de Google Sheets API in. Facturering is niet nodig.
  2. Stel Google Auth Platform in. Kies bij een persoonlijk account ‘External’ en voeg jezelf toe als testgebruiker.
  3. Maak onder ‘Clients’ een OAuth-client van het type ‘Web application’.
  4. Voeg als ‘Authorized JavaScript origin’ toe:
  5. Kopieer de client-ID naar het veld hierboven. Gebruik geen client secret.
